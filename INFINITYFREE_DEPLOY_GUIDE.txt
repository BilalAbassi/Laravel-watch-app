================================================================================
 TIMEYRAH - QUICK DEPLOYMENT GUIDE FOR INFINITYFREE
================================================================================

Step 1: Upload Files
--------------------
1. Log in to your InfinityFree Account -> Manage Account -> File Manager.
2. Open the "htdocs" folder (or your domain's htdocs folder).
3. Upload the contents of this ZIP directly into "htdocs".
   (If you upload the zip file itself, use the File Manager "Extract" button,
   or upload all files via FileZilla FTP).

Step 2: Create MySQL Database
------------------------------
1. In your InfinityFree Control Panel (vPanel), click "MySQL Databases".
2. Create a new database name, for example: timeyrah
   (Your full database name will be something like: if0_12345678_timeyrah)
3. Note your MySQL Details from the panel:
   - MySQL Host Name (e.g., sql300.infinityfree.com)
   - MySQL User Name (e.g., if0_12345678)
   - MySQL Password (your InfinityFree vPanel password)
   - MySQL Database Name (e.g., if0_12345678_timeyrah)

Step 3: Import Database Tables
------------------------------
1. In your vPanel, click "phpMyAdmin" next to your database name.
2. Click the "Import" tab at the top.
3. Click "Choose File" and select "database/infinityfree_database.sql".
4. Click "Go".
   All tables (users, sessions, cache, etc.) and the demo user will be created.

Step 4: Update .env File
------------------------
1. In the File Manager inside "htdocs", open the ".env" file (or rename env.txt to .env).
2. Update these lines with your details:
   APP_URL=http://your-subdomain.infinityfreeapp.com
   DB_HOST=sqlXXX.infinityfree.com
   DB_DATABASE=if0_XXXXXXXX_timeyrah
   DB_USERNAME=if0_XXXXXXXX
   DB_PASSWORD=your_vpanel_password
3. Save the file.

Step 5: Done!
-------------
Visit your website in your browser!
- Home page, Shop, Filters, and Checkout will work immediately.
- Login & Register work with your MySQL database.
